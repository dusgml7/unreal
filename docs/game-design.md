# 축영(逐影) 기획 요약

> 기획 문서(피그마) 내용을 Claude Code 작업용으로 옮긴 것이다. 수치나 동작이 비어 있는 부분은 "기획 확인 필요"로 표시했다.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 제목 | 축영(逐影) — 그림자를 쫓다 / 게임에서는 원혼에게 쫓기는 이중 의미 |
| 장르 | 공포 + 어드벤처 탈출 |
| 주제 | 궁궐에 나타난 장화홍련 자매의 원혼을 피하며 유품을 태워 한을 풀고 자매를 천도시키기 |
| 게임 목표 | 아침이 오기 전, 궁궐에 숨겨진 자매의 유품 4개(꽃신, 노리개, 댕기, 비녀)를 찾아 불로 태우기 |
| 핵심 재미 | ① 게이지 (공포 / 정신력) ② 한정적인 아이템 (등불 / 부채 / 방울 / 부적) ③ 진행할수록 난이도 상승 (추적 심화, 화면 밝기 어두워짐) |

## 2. 캐릭터

### PC (주인공)
- 설정: 왕의 명령을 받고 장화홍련 자매를 천도시키러 궁에 옴
- 시작 아이템: 무구(방울, 부채, 부적)와 등불

### 몬스터
| 이름 | 장화 | 홍련 |
|---|---|---|
| 설정 | 계모의 누명으로 쫓겨나 장쇠에게 끌려가 연못에 빠져 죽음 | 장화의 죽음에 슬퍼하다 같은 방법으로 자살 |
| 행동 패턴 | 물 발자국 소리, 물 떨어지는 소리를 동반 | 통곡 소리, 비명 소리 동반 |
| 관련 유품 | 꽃신, 노리개 | 댕기, 비녀 |

## 3. 게이지

| 게이지 | 공포 | 정신력 |
|---|---|---|
| 조건 | 자매를 일정 시간 **직시**하면 상승 | 자매가 내는 **소리**를 일정 시간 들으면 낮아짐 |
| 결과 (끝까지 갔을 때) | 환청 → 연못에서 자살 (게임 오버) | 속도 디버프 |
| 세부 설정 | — | 숨어 있어도 소리가 들리면 악화 |

### 추가 확정 사항
- **게이지 관련 디버프는 3단계**로 나뉜다.
  - 기획 확인 필요: 각 단계의 경계값(예: 33/66/100), 단계별 효과(속도 감소량, 화면 효과 등)
- **게이지 관련 사운드**: 헉헉 소리(숨소리), 심장 소리
  - 기획 확인 필요: 어떤 게이지에 어떤 소리를 붙일지, 단계별로 소리 크기·빠르기를 바꿀지

## 4. 코어 루프

1. **탐색** — 등불에 의지해 궁궐 조사
2. **감지** — 물소리(장화) / 곡소리(홍련) → 자매가 가까이 있음을 알아챔
3. **회피** — 시선 피하기(공포 게이지 관리), 병풍 뒤·장롱·마루 밑에 숨기 (숨어도 소리 때문에 정신력은 감소)
4. **회복** — 부채로 공포↓, 방울·부적으로 정신력↑, 등잔으로 등불 다시 밝히기

## 5. 메인 루프

1. [시작] 왕의 명령 · 무구와 등불 지급
2. 단서 찾기 — 일기(두루마리)로 자매의 사연·유품 단서 확인
3. 유품 발견 — 꽃신 / 노리개 / 댕기 / 비녀
4. 난이도 상승 — 스포그 강화, 화면 어두워짐, 자매 추적 강화
5. 남은 유품이 있으면 2번으로 (총 4회 반복)
6. 유품 4개 완료 → [최종 추격] 자매 동시 추격 + 방해 공격 + 유품 태우기
7. [엔딩] 탈출 성공 → 자매 천도 + 왕의 포상

## 6. 아이템

| 이름 | 효과 | 사용 횟수 | 세부 설정 |
|---|---|---|---|
| 부채 | 공포 게이지 회복 | 5회 | 1번 사용할 때마다 부채가 망가지게(외형 변화). 시작 기본 아이템 |
| 방울 | 정신력 게이지 회복 | 7회 | 한 번 흔들 때마다 방울 1개씩 사라짐(외형 변화). 시작 기본 아이템 |
| 부적 | 정신력 게이지 회복 | 3회 | 시작 기본 아이템 |
| 등불 | 앞을 밝혀 줌 | 일정 시간 | 시간이 지나며 밝기가 어두워짐. 시작 기본 아이템 |
| 등잔 | 등불을 다시 살려 줌 | 1회 | 궁 내부 랜덤 생성 |
| 일기(두루마리) | 자매의 스토리를 알게 해 줌 | 무한 | 유품 관련 내용. 두루마리는 생성된 곳에 계속 있음 |
| 쥐 사체 | 정신력 게이지 악화 | 1회 | 궁 내부 랜덤 생성 |
| 제웅(짚인형) | 정신력 게이지 악화 | 1회 | 궁 내부 랜덤 생성 |

기획 확인 필요: 아이템별 회복·악화 수치, 등불 지속 시간, 랜덤 생성 개수와 위치 규칙.

## 7. 은신처

| 공간 | 병풍 뒤 | 장롱 | 마루 밑 | 뒤주 | 항아리 |
|---|---|---|---|---|---|
| 차단 | 소리 차단 불가 | 소리 차단 가능 | 소리 차단 불가 | 시야 + 소리 차단 | 시야 + 소리 차단 |

- 시야 차단: 숨어 있는 동안 자매를 직시할 수 없음 → 공포 게이지가 오르지 않음
- 소리 차단: 숨어 있는 동안 자매 소리를 듣지 않음 → 정신력 게이지가 낮아지지 않음
- **추가 확정 사항: 유품 하나를 찾기 전까지 최대 5번 숨을 수 있다.** 유품을 찾으면 숨기 횟수가 다시 5번으로 돌아온다.
  - 기획 확인 필요: 5번을 다 쓰면 은신처 상호작용이 막히는지, UI에 남은 횟수를 표시하는지

## 8. 최종 추격전

- 유품을 다 태웠을 때 시간 초기화 → 추격 중 아침이 되어 끝나는 것을 막음
- 유품 태우는 것과 추격 시간은 따로 관리

| 단계 | 내용 |
|---|---|
| 발동 | 유품을 태우는 순간 물소리/통곡 소리, 화면 매우 어두워짐, 탈출 목표 표시 |
| 추격 | 장화·홍련 동시 추격 + 방해 공격 (아래) |
| 도착 | 탈출 지점 도달 시 추격 멈춤 |

방해 공격:
1. 물 웅덩이 — 속도 디버프
2. 마루 파괴 — 일정 시간 행동 저지
3. 귀신과의 거리 감소 — 정신력 감소와 공포 상승 속도 증가
4. 죽은 쥐 살아서 움직임(환영) — 게이지 영향
5. 궁궐 안에 병사들이 홀려서 움직임 — 동선 방해, 구현 어려울 듯
6. 주위 불 꺼짐 — 시야 혼선

세부 사항: 특정 문(탈출하기 위한 루트 제외 나머지 문)이 안 열리도록 함.

**추가 확정 사항: 최종 추격전 직전에 세이브 포인트**를 둔다. 추격전에서 죽으면 추격 직전 상태로 다시 시작.

## 9. UI

- **아이템 창, 게이지 창**: 디자인은 피그마 확인 (Claude Code는 C++ 부모 위젯과 데이터 연결까지만, 디자인은 사람이 에디터에서)
- **화면 오른쪽 사이드에 유품 아이템 창**: 유품 4개(꽃신, 노리개, 댕기, 비녀) 표시
- **비활성/활성화 상태**: 아직 못 찾은 유품·다 쓴 아이템은 비활성(흐리게), 가진 것은 활성
  - 기획 확인 필요: 유품의 상태가 "미발견 / 발견 / 태움" 3가지인지 2가지인지
