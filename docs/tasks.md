## 작업 1. 게이지 시스템 — `UChukGaugeComponent`

**공포 게이지 (0~100, 높을수록 나쁨)**
- 자매(몬스터)를 일정 시간 직시하면 상승
  - "직시" 판정: 카메라 시야 각도 안 + 사이에 막는 물체 없음(라인 트레이스). 각도와 상승 속도는 UPROPERTY
- 100 도달 시 `OnFearMaxed` 이벤트 (환청 → 연못에서 자살 = 게임 오버 연출은 블루프린트에서)

**정신력 게이지 (100~0, 낮을수록 나쁨)**
- 자매가 내는 소리를 일정 시간 들으면 감소
  - "들음" 판정: 자매와의 거리가 청취 반경 안. 반경과 감소 속도는 UPROPERTY
  - 숨어 있어도 은신처가 소리를 막지 못하면 계속 감소 (작업 4와 연결)
- 0 도달 시 속도 디버프 최대

**3단계 디버프**
- 각 게이지마다 단계 경계값 배열(기본값 예: 33 / 66 / 100)을 UPROPERTY로
- 단계가 바뀔 때 `OnFearStageChanged(int Stage)`, `OnSanityStageChanged(int Stage)` 델리게이트 발생
- 정신력 단계에 따라 이동 속도 배율 적용 (기본값 1.0 / 0.85 / 0.7 / 0.5, 전부 UPROPERTY) — `TODO(기획 확인)`
- 공포 단계별 효과는 이벤트만 열어 두고 블루프린트에서 연출 — `TODO(기획 확인)`

**게이지 사운드**
- 숨소리(헉헉), 심장 소리 `USoundBase*` 두 개를 UPROPERTY로 받음
- 단계가 올라갈수록 볼륨·재생 빠르기 올림 (단계별 배율 UPROPERTY)
- 어떤 게이지에 어떤 소리를 붙일지 선택할 수 있게 enum으로 — 기본값: 공포 → 심장 소리, 정신력 → 숨소리 `TODO(기획 확인)`

**외부에서 쓰는 함수 (BlueprintCallable)**
- `AddFear(float)`, `AddSanity(float)`, `GetFear()`, `GetSanity()`, `GetFearStage()`, `GetSanityStage()`

**완료 조건**: 빌드 성공. 블루프린트에서 `AddFear`를 호출하면 단계 이벤트가 발생하고 사운드가 바뀜.

## 작업 2. 몬스터 감지 대상 — `AChukSisterBase`

- 장화·홍련이 상속할 부모 클래스 (Character 기반)
- `SisterType` enum (장화 / 홍련)
- 청취 반경, 반복 재생할 소리(장화: 물 발자국·물 떨어지는 소리, 홍련: 통곡·비명) UPROPERTY
- 작업 1의 게이지 컴포넌트가 이 클래스를 찾아 직시/청취 판정을 하게 연결

## 작업 3. 아이템과 인벤토리 — `UChukInventoryComponent`

- 아이템 데이터: `FChukItemData` (이름, 아이콘 텍스처, 효과 종류, 효과량, 최대 사용 횟수, 남은 횟수)
  - DataTable로 편집할 수 있게 `FTableRowBase` 상속
- 기획서 6번 표의 아이템 8종: 부채(5회), 방울(7회), 부적(3회), 등불(시간제), 등잔(1회), 일기(무한), 쥐 사체(1회), 제웅(1회)
- 시작 아이템: 방울, 부채, 부적, 등불
- `UseItem(ItemId)`: 남은 횟수 감소 + 게이지 컴포넌트에 효과 적용
  - 남은 횟수가 바뀔 때 `OnItemUsesChanged(ItemId, Remaining)` 이벤트 → 부채가 망가지거나 방울이 하나씩 사라지는 외형 변화는 블루프린트에서 이 이벤트로 처리
  - 0이 되면 비활성 상태
- 등불: 시간이 지나며 밝기 감소 (지속 시간 UPROPERTY), 0이 되면 꺼짐. 등잔 사용 시 다시 최대 밝기. 밝기 값은 블루프린트의 라이트 컴포넌트에 연결할 수 있게 `GetLanternIntensity01()` 제공
- 쥐 사체·제웅: 획득(또는 상호작용) 시 정신력 악화
- 궁 내부 랜덤 생성(등잔, 쥐 사체, 제웅)은 **생성 지점 액터 `AChukItemSpawnPoint`**를 레벨에 배치하면 그중에서 랜덤으로 고르는 방식. 개수는 UPROPERTY

**완료 조건**: 빌드 성공. 아이템 사용 시 횟수 감소, 게이지 반영, 이벤트 발생.

## 작업 4. 은신처 — `AChukHideSpot`

- 종류 enum: 병풍 뒤 / 장롱 / 마루 밑 / 뒤주 / 항아리
- 종류별 기본값: 시야 차단 여부, 소리 차단 여부 (기획서 7번 표)
  - 병풍 뒤: 시야 X, 소리 X / 장롱: 시야 X, 소리 O / 마루 밑: 시야 X, 소리 X / 뒤주: 시야 O, 소리 O / 항아리: 시야 O, 소리 O
  - 기획서에 장롱·병풍·마루의 시야 차단 여부가 명시되지 않음 → 기본값 X, `TODO(기획 확인)`
- 숨는 중에는 게이지 컴포넌트가 차단 여부에 따라 공포 상승/정신력 감소를 멈춤
- **숨기 횟수 제한**: 유품 하나를 찾기 전까지 최대 5번. 유품을 찾으면 5번으로 초기화. 남은 횟수는 플레이어 쪽(컴포넌트)에서 관리하고 `OnHideCountChanged(Remaining)` 이벤트 제공
- 0번 남았을 때 숨기 시도 → 막고 `OnHideDenied` 이벤트 (`TODO(기획 확인)`)

- 최종 추격전 시작 직전에 자동 저장 (`OnAllRelicsFound` 또는 지정한 트리거 박스 액터 `AChukSavePointTrigger`)

## 작업 7. UI 부모 클래스 (디자인은 피그마 → 사람이 에디터에서)

C++에서는 **데이터 연결만** 하고, 실제 위젯 블루프린트는 사람이 이 부모 클래스를 상속해서 만든다.

- `UChukGaugeWidget`: 공포·정신력 ProgressBar (`BindWidget`), 게이지 컴포넌트 이벤트를 받아 갱신. 단계별 색/이미지 변경은 `BlueprintImplementableEvent`
- `UChukItemSlotWidget`: 아이콘 Image, 남은 횟수 Text, **활성/비활성 상태**(비활성이면 흐리게 — 투명도 값 UPROPERTY)
- `UChukItemBarWidget`: 아이템 슬롯 여러 개를 담는 창. 인벤토리 이벤트로 갱신
- `UChukRelicPanelWidget`: **화면 오른쪽 사이드**에 붙는 유품 창. 유품 4개 슬롯, 상태(미발견/발견/태움)에 따라 비활성/활성 표시
- `UChukHUDWidget`: 위 위젯들을 모은 메인 HUD. 플레이어 컨트롤러 BeginPlay에서 생성하는 코드 포함 (위젯 클래스는 UPROPERTY로 지정)

**완료 조건**: 빌드 성공. 사람이 에디터에서 해야 할 위젯 작업을 단계별로 정리해서 보고.
